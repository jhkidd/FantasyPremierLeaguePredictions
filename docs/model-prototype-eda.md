# Model prototype: exploratory data analysis

Generated by `fpl eda` (Phase A Steps 25-27). Every statistic below is computed **on the chronological training split only** (2016-17, 2017-18, 2018-19, 2019-20, 2020-21, 2021-22, 2022-23, 2023-24), 196479 row(s) — validation and test are never touched here, so nothing in this report has seen data the eventual model selection is meant to be blind to.

## 1. Feature type classification

Every column is one of five kinds: `identifier` (never a feature), `categorical` (nominal — `position`, `team_code`, `opponent_team_code`), `boolean` (`was_home` and the four `obs_*` era masks), `label` (the 13 prediction targets), or `numeric` (every rolling-window and team-context feature — the only kind the variance, skew, outlier, correlation, VIF and mutual-information sections below cover).

## 2. Missing values

341 of 489 column(s) have at least one null. Most missingness here is structural, not accidental: a numeric feature governed by an `obs_*` era mask (e.g. defensive-contribution stats, only recorded from 2023-24) is null for every row from a season before that stat existed, and the `_last_season`/`season_to_date` rolling windows are null for a player's first-ever recorded fixture (there is no history yet to roll over) — both are expected, not a data bug. The era breakdown below is an approximation: it uses each row's own `obs_*` flag as a proxy for the governing era, since a rolling window can straddle an era boundary.
